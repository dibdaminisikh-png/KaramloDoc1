# فرایند طراحی و تولید پروتز

صفحه فارسی راست‌به‌چپ، با کارت‌های شیشه‌ای سرمه‌ای و طلایی و نور دنبال‌کننده ماوس. شامل ۱۲ مرحله و ۱۰ تأیید بر اساس فایل Visio ارائه‌شده.

بدون وابستگی یا مرحله build. فایل `dist/index.html` را در مرورگر باز کنید یا پوشه `dist` را روی هاست استاتیک قرار دهید. برای GitHub Pages، workflow موجود پوشه `dist` را منتشر می‌کند؛ در Settings → Pages، منبع انتشار را GitHub Actions انتخاب کنید.

فونت وزیرمتن از Google Fonts بارگذاری می‌شود و در نبود اتصال، Tahoma جایگزین آن است. تنظیم کاهش حرکت سیستم رعایت می‌شود.

این صفحه نمایش فرایند است و وضعیت پرونده یا تأیید واقعی ثبت نمی‌کند. مقصد اتصال‌های برگشت بدون اتصال کامل در فایل اصلی، بر اساس چیدمان نمودار برداشت شده است.
